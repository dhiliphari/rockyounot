RockYouNot

Is your password already in a hacker's wordlist?

What is this?

In 2009 the social app RockYou was breached and over 14 million plaintext passwords were leaked. That list, rockyou.txt, is now one of the first wordlists attackers use when cracking passwords.

RockYouNot loads every password from that list into a Redis Bloom filter so you can check in an instant whether a password has been compromised. A "not found" result is definitive. A "found" result is correct about 99.9% of the time, because Bloom filters can occasionally report false positives.

Checked passwords are never saved. Added passwords only set bits in the Bloom filter, so the original text isn't kept.
